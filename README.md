This is restaurant management system developed in the C language. This project aims to automate the daily operations
of a restaurant, such as menu management, order taking, stock tracking, and invoice generation. Designed to be simple
and efficient, RestoManage-C offers a console-based interface that allows users to easily manage their activities.


Main Features
------------------------------------------------------------------------------------------------------------------------------------------------
Menu Management: Add, delete, and modify dishes.
Order Taking: Record orders with automatic total calculation.
Stock Management: Update ingredients after each order.
Billing: Generate detailed invoices for customers.
User-Friendly Interface: Interactive console menu for intuitive use.

Technologies Used
------------------------------------------------------------------------------------------------------------------------------------------------
C Language
Standard Libraries: stdio.h, stdlib.h, string.h
Development Environment: Code::Blocks, Visual Studio Code

Objective
------------------------------------------------------------------------------------------------------------------------------------------------
This project was carried out as part of a university mini-project to demonstrate the effectiveness of the C language in
creating simple and efficient management systems. It can also serve as a foundation for more complex projects, such as integrating a 
graphical interface or a database.
